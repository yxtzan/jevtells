- **视觉参考**：
  - 带真实画面的设计稿放在本地 `design/` 目录（不提交，含版权画面）：`D_h.png` / `D_h.html`（横屏）、`D_v.png` / `D_v.html`（竖屏，不重构图）、`D_v_reframe.png` / `D_v_reframe.html`（竖屏智能重构图，M5 起竖屏默认用这个）。HTML 可以直接用浏览器打开，查看精确的 CSS 数值。

  - 画面内（叠在视频上）用 C「体育转播风」：黑底荧光绿胶囊标签、粗引线。

## 2b. 竖屏 3:4，智能重构图（`--reframe auto`，M5 起默认）

**目的**：16:9 原片直接缩进竖屏，人物太小。重构图从原片里裁出一个 4:3 的窗口，**保留完整高度、只在水平方向裁**，放大到 1080×810。保留完整高度，是为了不切掉原片底部烧录的字幕。

**裁切规则**：

- 只在原片比 4:3 更宽时生效（如 16:9）；否则自动按 `off` 处理。
- 裁切窗口：高 = 原片高，宽 = 原片高 × 4/3（720p 原片是 960×720）。
- **按镜头固定**：每个镜头算一次裁切位置，镜头内不移动（避免「摇镜头」的晃动感）。镜头切换时直接跳到新位置（原片本来就在切）。只有当主角在一个镜头内移出裁切窗口超过窗口宽度的 10%、并持续 1 秒以上时，才用 600ms（ease-in-out）平移重新居中。
- 主角在画面的镜头：窗口中心对准该镜头主角范围（§4.1）的水平中心。主角不在画面的镜头：取画面中心。
- **保字幕**：传了 `--subtitles off`（约定含义：原片已烧录字幕）时，先估计烧录字幕的水平范围（在视频底部 20% 的条带里，按列统计各采样帧的文字边缘），裁切窗口必须完整包含这个范围；放不下时以字幕范围的中心为窗口中心。检测不到字幕时，窗口中心最多偏离画面中心 `render.reframe.max_offset` × 原片宽（默认 0.08）。
- 模糊区域在原片坐标里先模糊，再裁切。所有画面内元素（标签、引线端点）按裁切变换换算坐标。

## 4. 画面内元素（两种画幅通用）

- **手势标签**：
  - 主体：INK 胶囊、LIME 文字、900 字重；竖屏 28px，横屏 22px。
  - 下方小徽章：白底 INK 字，内容如「幅度大 · 表达欲 0.76」。手型类动作没有幅度，只写表达欲。
- **位置**：每只手一个标签位，按镜头自动选取（§4.1）。M4 的固定位置作为找不到合适位置时的兜底：
  - 竖屏（不重构图）：(28,300)、(800,300)
  - 横屏：(40,196)、(968,92)
- **引线**：LIME，3.5px（横屏按比例缩放）。从标签边缘先水平走 35%，再斜向连到手部中心（每帧用平滑后的手部关键点更新）。末端是 LIME 圆点：半径 9，INK 描边 2.5。
- **显示哪些动作**（config 中的 `render.label_types`）：默认显示抬手、下压、张开手掌、双手展开、双手收拢、节拍强调、点头、摇头；默认不显示掌心朝上、指点、握拳；small 幅度的动作不显示；远景中的动作不显示（见 SPEC §7「远景」）。

### 4.1 标签自动选位（M5）

每个镜头计算一次，结果缓存到 `work/<clip_id>/layout_<h|v>.json`，同样的输入必须得到同样的位置。

1. **主角范围**：该镜头内主角所有可见的 pose 点和手部点，取第 5–95 百分位的外接框，四周各扩 0.15 倍肩宽。手会动，所以范围包含手的活动区域。
2. **禁区**：主角范围；视频底部的字幕条带（视频高度的 20%，可配置）；模糊区域；横屏的解说条、引语卡、判定卡片（当前所在侧）、状态胶囊；视频边缘 24px（设计尺寸）的安全边距。
3. **首选**：画面左侧的手（说话人的右手）的标签放在主角范围的左边，另一只手放右边；纵向优先放在手的上方，与设计稿一致。
4. **一侧放不下**：两个标签都放到有空间的一侧，上下叠放，间距 12px。叠放顺序要让两条引线不交叉（用该镜头内两只手的中位位置，两种顺序都算一遍）。
5. **评分**：在合法位置中选「离首选位置最近、引线最短」的。引线长度超过视频宽度 45% 的位置不选。
6. **兜底**：没有任何合法位置时用 M4 的固定位置，并在 `layout_<h|v>.json` 里记一条 `fallback`。
7. **镜头切换时**：旧标签立即消失（原片本来就在切），新镜头的标签按 §5 的规则正常出现。

### 4.2 横屏判定卡片换边（M5）

- 每个镜头决定一次：比较主角范围左右两边到画面边缘的空白宽度。右边空白够放卡片（卡片宽 + 24 边距）就放右边；右边不够而左边够，就放左边；两边都不够，放空白更大的一边，卡片允许压在主角范围上，但不能压住字幕条带。
- 只在镜头切换时换边，用 400ms（ease-in-out-cubic）滑过去；镜头内不换。
- 卡片换边时，状态胶囊同时换到另一侧，标签位置按新禁区重新计算。

## 5. 动态规则（30 fps）

| 场景 | 规则 |
|---|---|
| 进入新窗口 | 数字从旧值过渡到新值，进度条同步变化，时长 300ms，ease-out-cubic；走势线新增一个点，展开 300ms |
| 解说切换（M5 修改） | **先后进行，不重叠**：旧解说和旧引语先用 150ms 淡出，完全消失后，新解说再淡入并上移 12px（250ms）。任何一帧上最多只有一句解说可见 |
| 解说区高度（M5 修改） | 解说区的高度按全片所有解说里最多的行数固定，下面的内容不随单句行数跳动 |
| 走势线、情绪弧 | 横轴固定为全片所有窗口，只画到当前窗口；后面的窗口留空，不剧透 |
| 手势标签 | 在事件开始时出现：淡入，同时从 0.9 倍缩放到 1，用时 150ms；保持到事件结束后 0.8 秒；再用 200ms 淡出。同一只手同一时间只显示一个标签 |
| 第一个窗口之前 | 场外只显示顶栏和「等待第一句…」 |
| 窗口之间的空隙 | 保留上一个窗口的内容，整体降低透明度 |
| 他人发言的窗口 | 解说位置显示灰字「（他人发言，本句不做判定）」，数字显示「—」，情绪弧对应的格子用斜线纹；手势标签照常显示 |
| 主角丢失 | 隐藏手势标签，状态胶囊变灰并显示「目标丢失」 |
| 判定缺失（API 失败） | 对应位置显示「—」 |

## 6. 文字与编号

- 对外显示的编号一律从 1 开始：编号块写 `W08`，状态胶囊写「31.6s · 窗口 8/8 · 目标已锁定」。
- 标题来自 `--title`，默认是「AI 读{--speaker}」。
- 页脚的模型名用**短名**（M5 修改）：如「判定 Jev 1.13 · 解说 Gemini Flash Lite」。短名来自 config 的映射表；表里没有的模型，去掉厂商前缀和日期后缀后显示。实际使用的完整模型 ID 照常写进 `run_meta.json`。
- 所有界面文字都走 i18n（`--lang`）。
