# 渲染设计规范（M4）

成片的视觉规范，用户于 2026-10-04 选定。

- **视觉参考**：
  - 带真实画面的设计稿放在本地 `design/` 目录（不提交，含版权画面）：`D_h.png` / `D_h.html`（横屏）、`D_v.png` / `D_v.html`（竖屏）。HTML 可以直接用浏览器打开，查看精确的 CSS 数值。
  - 不含画面的版式图放在 `docs/design/layout_h.png`、`layout_v.png`。
- **风格来源**：
  - 画面内（叠在视频上）用 C「体育转播风」：黑底荧光绿胶囊标签、粗引线。
  - 场外（视频以外的区域）用 B「杂志风」的排版 + A 的数据组件，C 的配色，黑色背景。

## 4. 画面内元素（两种画幅通用）

- **手势标签**：
  - 主体：INK 胶囊、LIME 文字、900 字重；竖屏 28px，横屏 22px。
  - 下方小徽章：白底 INK 字，内容如「幅度大 · 表达欲 0.76」。手型类动作没有幅度，只写表达欲。
- **固定位置**：每侧一个标签位，标签只跟着对应的手。画面左侧的手（说话人的右手）用左边的位，另一只手用右边的位。
  - 竖屏：(28,300)、(800,300)
  - 横屏：(40,196)、(968,92)
- **引线**：LIME，3.5px（横屏按比例缩放）。从标签边缘先水平走 35%，再斜向连到手部中心（每帧用平滑后的手部关键点更新）。末端是 LIME 圆点：半径 9，INK 描边 2.5。
- **显示哪些动作**（config 中的 `render.label_types`）：默认显示抬手、下压、张开手掌、双手展开、双手收拢、节拍强调、点头、摇头；默认不显示掌心朝上、指点、握拳；small 幅度的动作不显示。
- **避让区**：
  - 原片烧录字幕所在的底部条带：视频高度的 20%，可配置。
  - 水印区域（已模糊）。
  - 横屏右侧的判定卡片。

## 5. 动态规则（30 fps）

| 场景 | 规则 |
|---|---|
| 进入新窗口 | 数字从旧值过渡到新值，进度条同步变化，时长 300ms，ease-out-cubic；走势线新增一个点，展开 300ms；解说淡入并上移 12px（250ms），旧解说淡出（150ms） |
| 走势线、情绪弧 | 横轴固定为全片所有窗口，只画到当前窗口；后面的窗口留空，不剧透 |
| 手势标签 | 在事件开始时出现：淡入，同时从 0.9 倍缩放到 1，用时 150ms；保持到事件结束后 0.8 秒；再用 200ms 淡出。同一侧同一时间只显示一个标签 |
| 第一个窗口之前 | 场外只显示顶栏和「等待第一句…」 |
| 窗口之间的空隙 | 保留上一个窗口的内容，整体降低透明度 |
| 他人发言的窗口 | 解说位置显示灰字「（他人发言，本句不做判定）」，数字显示「—」，情绪弧对应的格子用斜线纹；手势标签照常显示 |
| 主角丢失 | 隐藏手势标签，状态胶囊变灰并显示「目标丢失」 |
| 判定缺失（API 失败） | 对应位置显示「—」 |

## 6. 文字与编号

- 对外显示的编号一律从 1 开始：编号块写 `W08`，状态胶囊写「31.6s · 窗口 8/8 · 目标已锁定」。
- 标题来自 `--title`，默认是「AI 读{--speaker}」。
- 页脚的模型名从实际配置和响应中读取，不写死。
- 所有界面文字都走 i18n（`--lang`）。
