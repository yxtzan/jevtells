## 2b. 竖屏 3:4，智能重构图（`--reframe auto`，M5 起默认）

**目的**：16:9 原片直接缩进竖屏，人物太小。重构图从原片里裁出一个 4:3 的窗口，**保留完整高度、只在水平方向裁**，放大到 1080×810。保留完整高度，是为了不切掉原片底部烧录的字幕。

**裁切规则**：

- 只在原片比 4:3 更宽时生效（如 16:9）；否则自动按 `off` 处理。
- 裁切窗口：高 = 原片高，宽 = 原片高 × 4/3（720p 原片是 960×720）。
- **按镜头固定**：每个镜头算一次裁切位置，镜头内不移动（避免「摇镜头」的晃动感）。镜头切换时直接跳到新位置（原片本来就在切）。只有当主角在一个镜头内移出裁切窗口超过窗口宽度的 10%、并持续 1 秒以上时，才用 600ms（ease-in-out）平移重新居中。
- 主角在画面的镜头：窗口中心对准该镜头主角范围（§4.1）的水平中心。主角不在画面的镜头：取画面中心。
- **字幕条模式**（`render.reframe.oversized_subtitles`，默认 `strip`）：传了 `--subtitles off`（约定含义：原片已烧录字幕）时，每 0.5 秒检测一次烧录字幕的水平范围。某句宽度超过「裁切宽度 − 左右各 16px」、且连续 ≥ 2 个采样点都这样，就算放不下；只在一个采样点出现的视为噪声。有放不下的句子时，全片改用字幕条：
  - 画面：裁切窗口去掉底部字幕带（原片 y 0 到 `strip_y`），缩放到 1080 宽（720p 原片约 1080×648）
  - 字幕条：原片底部字幕带（`strip_y` 到底边）全宽缩放到 1080 宽（约 1080×122），放在画面下方，中间 8px 黑带
  - 两者合起来在视频区里垂直居中
  - `strip_y` = min(0.8 × 原片高, 检测到的字幕文字最上沿 − 6px)
  - 标签和引线只能在画面部分
  - 另外两个取值：`center` 以字幕范围中心为窗口中心（可能切掉字）；`off` 放不下就整段不重构图
  - `--subtitles on`（工具自己画字幕）时不用字幕条
- 模糊区域在原片坐标里先模糊，再裁切。所有画面内元素（标签、引线端点）按裁切变换换算坐标。

## 4. 画面内元素（两种画幅通用）

- **手势标签**：
  - 主体：INK 胶囊、LIME 文字、900 字重；竖屏 28px，横屏 22px。
  - 下方小徽章：白底 INK 字，内容如「幅度大 · 表达欲 0.76」。手型类动作没有幅度，只写表达欲。
- **位置**：每只手一个标签位，按镜头自动选取（§4.1）。M4 的固定位置（竖屏 (28,300)、(800,300)；横屏 (40,196)、(968,92)）只在没有镜头数据时使用。
- **引线**：LIME，3.5px（横屏按比例缩放）。从标签边缘先水平走 35%，再斜向连到手部中心（每帧用平滑后的手部关键点更新）。末端是 LIME 圆点：半径 9，INK 描边 2.5。
- **显示哪些动作**（config 中的 `render.label_types`）：默认显示抬手、下压、张开手掌、双手展开、双手收拢、节拍强调、点头、摇头；默认不显示掌心朝上、指点、握拳；small 幅度的动作不显示；远景中的动作不显示（见 SPEC §7「远景」）。

### 4.1 标签自动选位（M5，v0.5.0 定稿）

每个镜头计算一次，结果缓存到 `work/<clip_id>/layout_<h|v>.json`，同样的输入必须得到同样的位置。几何约束只用于**选位置**：一旦某个动作的标签该显示，标签、引线、手部圆点三者必须同时完整画出，任何一帧都不因几何原因隐藏。

1. **标签矩形的硬禁区**：
   - 脸框：鼻、眼、耳、嘴的 pose 点的外接框，四周扩 0.15 倍肩宽
   - 字幕条带 / 字幕条、模糊区域、判定卡片、界面元素、其他标签、安全边距
2. **软禁区**（按重叠面积扣分）：躯干核心（两肩之间、肩到髋），手的活动范围。
3. **引线规则**：
   - 不穿过脸框
   - 不越过身体中线（经过两肩中点的竖线）
   - 离手部端点 60px（设计尺寸）以内的部分不算，所以手抬到脸边时引线停在手上是允许的
   - 合格的条件：该标签在镜头内显示的所有帧中，至少 95% 的帧满足，按每帧真实的手部位置检查
4. **选位置顺序**：
   1. 手所在的一侧（按手在中线的哪一边判断），包括手的上方
   2. 引线合格的对侧
   3. 手所在一侧、只遵守硬禁区（记 `relaxed`）
   4. 手所在一侧、和脸重叠最少（记 `forced`）
5. **镜头切换时**：旧标签立即消失，新镜头的标签按 §5 的规则正常出现。
6. **审计**：`scripts/check_layout.py` 逐帧统计碰撞、穿脸、越中线、隐藏标签、隐藏引线。碰撞、穿脸、隐藏标签、隐藏引线必须为 0；越中线如实报告。

### 4.2 横屏判定卡片换边（M5，v0.5.0 定稿）

- 空白宽度按主角的躯干核心计算（手的活动范围不算）。
- 顺序：右侧放得下 → 右侧；右侧放不下、左侧放得下 → 左侧；两侧都放不下 → 右侧，只有左侧空白 ≥ 右侧的 1.5 倍时才放左侧。
- 只在镜头切换时换边，用 400ms（ease-in-out-cubic）滑过去，滑动期间标签隐藏；状态胶囊跟着换侧，标签按新禁区重算。

## 5. 动态规则（30 fps）

| 场景 | 规则 |
|---|---|
| 进入新窗口 | 数字从旧值过渡到新值，进度条同步变化，时长 300ms，ease-out-cubic；走势线新增一个点，展开 300ms |
| 解说切换（M5 修改） | **先后进行，不重叠**：旧解说和旧引语先用 150ms 淡出，完全消失后，新解说再淡入并上移 12px（250ms）。任何一帧上最多只有一句解说可见 |
| 解说区高度（M5 修改） | 解说区的高度按全片所有解说里最多的行数固定，下面的内容不随单句行数跳动。竖屏分析区有余量时，平均分到三个间隔（引语与数字之间、数字与意图情绪之间、意图情绪与页脚之间），每个最多加 32px；小标题到大字至少 6px，大字到第一行概率条至少 8px |
| 走势线、情绪弧 | 横轴固定为全片所有窗口，只画到当前窗口；后面的窗口留空，不剧透 |
| 手势标签 | 在事件开始时出现：淡入，同时从 0.9 倍缩放到 1，用时 150ms；保持到事件结束后 0.8 秒；再用 200ms 淡出。同一只手同一时间只显示一个标签 |
| 第一个窗口之前 | 场外只显示顶栏和「等待第一句…」 |
| 窗口之间的空隙 | 保留上一个窗口的内容，整体降低透明度 |
| 他人发言的窗口 | 解说位置显示灰字「（他人发言，本句不做判定）」，数字显示「—」，情绪弧对应的格子用斜线纹；手势标签照常显示 |
| 主角丢失 | 隐藏手势标签，状态胶囊变灰并显示「目标丢失」 |
| 判定缺失（API 失败） | 对应位置显示「—」 |

## 6. 文字与编号

- 对外显示的编号一律从 1 开始：编号块写 `W08`，状态胶囊写「31.6s · 窗口 8/8 · 目标已锁定」。
- 标题来自 `--title`，默认是「AI 读{--speaker}」。
- 页脚的模型名用**短名**（M5 修改）：如「判定 Jev 1.13 · 解说 Gemini 3.8 Flash」。短名来自 config 的映射表；表里没有的模型，去掉厂商前缀和日期后缀后显示。实际使用的完整模型 ID 照常写进 `run_meta.json`。
- 所有界面文字都走 i18n（`--lang`）。

## 7. 多人镜头与状态（M6，v0.6.0）

- **竖屏**：多人时段显示完整画面（在视频区里垂直居中，上下是黑边），单人时段放大。在切镜点上直接切换；镜头内用 600ms ease-in-out 缩放。完整画面时不另外显示字幕条。
- **横屏卡片**：
  - 不判定的窗口里，卡片在 300ms 内收成「JEV · 他人发言」/「JEV · 主角不在画面」小标签。
  - 有判定、但两侧完整卡片都会压到人脸时，用一行的迷你卡片：三个数字和意图，放在字幕带上方。
- **不确定**：意图或情绪的最高概率 < 0.40 时，大字显示「不明显」（MUTED 色）；情绪弧格子用标签色的 40% 透明度。
- **状态胶囊**：主角离画显示「主角不在画面」，镜头内跟丢才显示「目标丢失」。情绪弧里没有判定的格子，图例统一叫「未判定」。
- **同一只手换动作**：标签在原位用 100ms 交叉淡化换文字，引线不动。
