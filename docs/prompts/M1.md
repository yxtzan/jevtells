# 任务：JevTells · M1 项目骨架 + 数据层 + 调试视频

你负责实现这个项目。设计由另一位架构师负责，你交付的代码和实际输出会被逐行审查。

## 开始前

1. 完整阅读 `docs/SPEC.md`。本任务**只做 M1 范围**。
2. 测试视频：`samples/<视频文件名>`（约 30 秒），说话人：`<说话人名字>`。
3. 你必须能真正执行命令（建 venv、装依赖、跑脚本、查看输出）。任何一步无法执行，就停下来报告，不要假装完成。

## M1 要做的

1. **项目骨架**：按 SPEC §4 建好目录。包括：
   - `pyproject.toml`（console script 名为 `jevtells`）
   - `requirements.txt`（锁版本）
   - `.gitignore`、`.env.example`、`LICENSE`（MIT）
   - `config/default.yaml`
   - `README.md`：先只写安装步骤和 M1 用法
   - 初始化 git
2. **`scripts/download_models.py`**：下载 MediaPipe 的 pose landmarker（full）和 hand landmarker 模型到 `models/`，下载 Noto Sans SC 字体到 `assets/fonts/`。已存在则跳过。
3. **阶段实现**：`prepare / pose / asr / voice / shots / segment / state`（SPEC §3、§6）。
   - 每个阶段写自己的文件、带缓存，支持 `--force / --from / --until`。
   - `state` 阶段里，`measured_actions` 暂用占位的「运动统计」文字，例如 `"left wrist: total travel 1.8 shoulder-widths, max height above shoulder 0.3"`。M2 会替换掉。
   - `scene` 取 `--scene` 参数，没有则填 `"unknown"`。
   - `asr` 阶段支持 `--srt`：传了就跳过转写、直接导入（见 SPEC §5「转写」）。
4. **调试视频 `debug.mp4`**（`--until state` 时输出）：
   - 画出身体骨架连线和双手 21 个点
   - 说话人的左手、右手用两种不同颜色，并在手旁标出 L / R
   - 左上角显示 `t=`、当前窗口号、shot 标签
   - 底部显示当前窗口字幕（用 Pillow + Noto Sans SC 绘制，中文不能乱码）
   - 保留原音轨
5. **截图**：从 `debug.mp4` 截 3 帧 PNG 存到 `work/<clip_id>/snapshots/`：片段 25% 处、75% 处，以及你在 A4 中用来确认左右手的那一帧。
6. **`run_meta.json`**：记录依赖版本、参数、各阶段耗时、检测率。
7. **测试**：在 `tests/` 下用合成数据（不依赖视频）至少覆盖：
   - 窗口切分规则（合并短句、在词边界切开长句、静音段）
   - 手与 pose 手腕的左右匹配

## M1 不做的

- 动作识别规则（M2）
- 任何 API 调用（M3）
- 正式渲染（M4）

## 必须遵守（详见 SPEC §5）

- 左右手用「手的 wrist ↔ pose 15 / 16 号点」最近距离匹配，**不用** handedness 标签
- **不装** `opencv-python`；`scenedetect` **不带** `[opencv]` extra
- 视频通过 ffmpeg 管道编码（libx264 / yuv420p），并 mux 回原音轨
- 和 SPEC 冲突、或 SPEC 没写清楚的地方：选最简单的做法，在报告第 5 节写明；不要扩展范围

## 验收标准（逐条自测）

- **A1**：在全新 venv（Python 3.11）中按 README 安装依赖、下载模型，全程无报错。
- **A2**：执行 `jevtells run samples/<视频文件名> --speaker "<说话人名字>" --until state`，在 `work/<clip_id>/` 下生成：`clip.mp4`、`audio.wav`、`keypoints.npz`、`transcript.json`、`voice_features.json`、`shots.json`、`windows.json`、`states.json`、`debug.mp4`、`run_meta.json`、`snapshots/`。
- **A3**：`debug.mp4` 的时长、fps 与 `clip.mp4` 一致，音画同步，骨架贴合身体。用 ffprobe 输出作为证据。
- **A4**：左右手判定正确。找一个说话人明显只动一只手的时刻，确认标 L 的是说话人自己的左手（注意：画面左右与说话人左右相反）。
- **A5**：每个窗口 2–5 秒（静音窗口除外），边界落在词边界上。打印窗口数量和每个窗口的时长。
- **A6**：`states.json` 中每个窗口正好 5 个字段，并通过 pydantic 校验。
- **A7**：第二次运行命中缓存，几秒内完成；加 `--force` 会全部重跑。
- **A8**：`pytest` 全部通过。
- **A9**：M1 全程不需要 `OPENROUTER_API_KEY`。
