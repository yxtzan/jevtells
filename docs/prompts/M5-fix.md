## 1. 解说（最重要）

**问题**：M5 最终版黄仁勋 7 句解说里有 4 句走了模板兜底，最后一句只剩「自信度比上一句 +0.12」，比 M4 差。看 `narrate_meta.json` 的失败原因：
- 当前模型（gemini-3.1-flash-lite）经常超长；
- 逐句生成时，模型看不到后面几句，满足不了「开头不重复」「「 前两个字不重复」这类跨句的规则。

**1a. 全片一次生成。**
- 把全片所有窗口的 facts 按顺序放进**一次**调用，让模型返回 `{"lines": [{"id": "W01", "line": "...", "quote": "..."}, ...]}`。模型在一次输出里自己安排句式变化。
- 他人发言的窗口不放进去，仍然记 null。
- 校验规则不变：M4 的全部规则，加上 M5 的两条跨句规则，再加 1c 的「不出现数字」。
- 不合格的句子**合起来重试一次调用**：把已通过的句子作为固定上下文，并附上每句的失败原因。最多重试 2 轮，仍不合格的句子才走兜底。
- 重写 `config/narrate_prompt.md`，保留 M4 的事实约束和语气红线。
- 重试轮数、兜底句数照常写进 `narrate_meta.json`。

**1b. 模型对比。** 到 openrouter.ai/models 确认当前的模型 ID，至少比较以下几个：
- 现在的 gemini-3.1-flash-lite（作为基线）
- Gemini 当前的 Flash（非 Lite）
- Claude 当前的 Haiku
- DeepSeek 当前的对话模型
- Qwen 当前的对话模型（中文强）

每个模型都在黄仁勋（中文）上用**同一份 facts** 跑一遍全片生成，记录：兜底句数、重试轮数、费用、耗时，以及每一句解说。默认模型选兜底最少的；兜底一样时选更便宜的。把选中的模型写进 config，并在报告里说明理由。所有候选的全部句子都要贴进报告，用户和架构师要按文笔挑。对比部分的费用不超过 0.15 美元。

**1c. 解说里不出现数字，兜底模板改成像人话的句子。**
- 解说句子里**不允许出现阿拉伯数字**。数字已经显示在下方的数据区，标题只用文字描述变化，例如「自信度明显上升」「升至全场最高」。把这条加进提示词和校验。
- 亮点转成文字的规则放进 i18n：
  - 变化 ≥ 0.10 写「明显上升 / 明显下降」，0.08–0.10 写「有所上升 / 有所下降」
  - 最高 / 最低写「升至全场最高 / 降至全场最低」
  - 持续变化写「持续走高 / 持续走低」
  - 意图或情绪转变写「转为…」
- 兜底模板按以下顺序选第一个可用的：
  1. 「{动作}，{亮点文字}」
  2. 「{亮点文字}」
  3. 「{意图}，语气{情绪}」
- 兜底句子也要通过除「开头不重复」以外的全部校验。

**目标**：黄仁勋 7 句里兜底不超过 1 句；5 段素材合计兜底比例不超过 15%；所有句子里没有数字。

## 2. 标签选位：引线不横穿身体

**问题**：`jensen_left` 横屏 2 秒的截帧里，画面左侧那只手的标签被放到了画面右侧。引线从 x≈87 一直拉到 x≈1180，横穿了整个身体和另一只手。原因是主角范围把手的活动区也算成了禁区，左侧没地方放，标签只好去了对面。

**改法**（替换 design.md §4.1 的第 1–5 条）：

- **硬禁区**（标签不能压）：
  - 脸：由鼻、眼、耳、嘴的 pose 点算出外接框，四周扩 0.35 倍肩宽
  - 躯干核心：两肩之间、从肩到髋（髋不可见时到视频底边）
  - 原有的字幕条带、模糊区域、卡片、界面元素、其他标签、安全边距
- **软禁区**：手的活动范围（M5 的第 5–95 百分位外接框）。压到这部分要扣分，扣分和重叠面积成正比，但可以压。
- **引线硬约束**：按镜头内手的中位位置算出引线（先水平、再斜向的折线），不能穿过脸或躯干核心。
- **选侧顺序**：
  1. 标签优先放在它那只手所在的一侧，包括这一侧手的上方。
  2. 只有当引线不穿过脸和躯干时，才允许放到对侧。
  3. 两种都不行：用这一侧的 M4 固定位置兜底并记录，**不放对侧**。
- `check_layout.py` 增加逐帧检查：用每帧真实的手部位置画出引线，统计穿过脸框的帧数、穿过躯干核心的帧数。

**目标**：
- 5 段素材两种画幅，标签碰撞为 0，引线穿脸为 0。
- 穿躯干的帧数如实报告。
- `jensen_left` 横屏 2 秒时，画面左侧那只手的标签在画面左半边。

## 3. 竖屏分析区排版

**问题**：解说只有一行时，分析区下方空出约 100px（见 `v_13.8s.png`、`v_31.63s.png`）；「意图 / 情绪」小标题、大字、第一行概率条三者挤在一起。

- **余量分配**：分析区内容的总高度小于可用高度时，把多出的空间平均分到三个间隔里：引语与数字之间、数字与意图情绪之间、意图情绪与页脚之间。每个间隔最多加 32px，再多出来的留在底部。全片按最大内容高度算一次，整片不变（A5 的原则不变）。
- **间距**：
  - 小标题到大字至少 6px
  - 大字到第一行概率条至少 8px
  - 两种竖屏版式（重构图 / 不重构图）都要检查

## 4. 横屏判定卡片默认在右侧

**问题**：黄仁勋在画面正中时，两边空白都不够放卡片，M5 选了空白稍大的左侧。设计稿和品牌印象是右侧。

- **新规则**：
  1. 右侧放得下 → 放右侧。
  2. 右侧放不下、左侧放得下 → 放左侧。
  3. 两侧都放不下 → 放右侧；只有左侧空白 ≥ 右侧的 1.5 倍时才放左侧。
- 其余（只在镜头切换时换边、400ms 滑动）不变。

**目标**：
- 黄仁勋原片 31.63 秒横屏卡片在右侧。
- `jensen_left` 在右侧。
- `jensen_cut` 仍然按镜头换边。

## 5. 字幕条模式（用户选定的方案 C）

**问题**：黄仁勋 17–21 秒那句英文宽约 1176px，放不进 960px 的裁切窗口，M5 按居中处理切掉了两头。其他句子都放得下。

**用户决定**：只要有一句放不下，这段视频的竖屏就改用「字幕条」版式。人物照样放大，原字幕整条移到画面下方，全宽缩小显示。参考图是 `work/_review/reframe_subtitle_options.png` 最右边的方案 C（用 `work/_review/src_20s.png` 拼出来的示意）。规则：

- **触发**：`--reframe auto` 且 `--subtitles off` 时，用 M5 的烧录字幕检测逐句判断。某句的宽度超过裁切窗口宽度减去两侧各 16px 时，记为放不下。
  - 只在 1 个采样点出现的宽度视为噪声（例如黄仁勋 10 秒处的 [472, 1242]）：要求连续 ≥ 2 个采样点。采样间隔改为 0.5 秒。
  - 有放不下的句子，全片用字幕条；全部放得下，照 M5 的做法。
- **字幕带的上边界** `strip_y`：取 0.8 × 原片高和「检测到的字幕文字最上沿减 6px」中较小的那个，防止切到字幕的上半截。
- **几何**（以 720p 原片为例）：
  - 画面：原片裁切窗口 (x0, 0, 960, strip_y)，缩放到 1080 宽，约 1080×648
  - 字幕条：原片 (0, strip_y, 原片宽, 原片高 − strip_y)，全宽缩放到 1080 宽，约 1080×121
  - 画面在上，字幕条在下，中间 8px 黑色间隔；这一整块在视频区（y 150–960）里垂直居中
- 模糊仍在原片坐标里先做，再裁切。
- 标签和引线只能在画面部分；字幕条整个是禁区。画面部分不再需要避让底部字幕带，只留安全边距。
- config 增加 `render.reframe.oversized_subtitles: strip | center | off`，默认 `strip`。`center` 是 M5 现在的行为，`off` 表示放不下就整段不重构图。
- `--subtitles on`（工具自己画字幕）时不用字幕条，字幕画在重构后的画面上。
- **测试**：
  - 模式选择：全部放得下、某句放不下、单点噪声被忽略
  - `strip_y` 计算
  - 两块区域的坐标变换
  - 标签不进字幕条
