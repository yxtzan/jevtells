## B. OpenRouter 客户端（`src/jevtells/clients/openrouter.py`）

- 所有网络调用只在这一个文件里发生。
- 两个函数：
  - `decide(state, questions, model)`：调用 `POST https://openrouter.ai/api/alpha/decisions`
  - `chat(messages, model, ...)`：调用 `POST https://openrouter.ai/api/v1/chat/completions`，需要时附带图片
- key 从 `.env` 读取（用 python-dotenv）。缺少 key 时报错：`缺少 OPENROUTER_API_KEY：请把 .env.example 复制为 .env 并填写`。
- 超时、429、5xx 时指数退避重试 3 次；其他 4xx 不重试，直接报出状态码和响应体。
- 每次调用返回原始响应和费用（响应里的 `usage.cost`，没有就记 null）。

## C. 先做冒烟测试（必须在 D 之前完成）

- 新建 `scripts/jev_smoke.py`：用一个最小的 state 和三道题（choice、score、noul 各一道）调用一次 Jev，把原始响应存为 `work/_api/jev_smoke.json`，并打印费用。
- **以实际返回为准**，核对字段：choice 的选项和概率、score 的分值和 legend、noul 的概率、confidence。实际格式与 SPEC 或文档不一致时，以实际为准写代码，并在报告里写明差异。

## D. judge 阶段（`stages/judge.py`）

- 问题定义放在 `config/jev_questions.yaml`（英文），包括：`confidence`、`focus`、`tension`（score，5 档）；`intent`（choice，10 个选项）；`emotion`（choice，7 个选项）；以及每个动作的 `action_<k>_expressive`（noul，在 instructions 里用反引号引用 `` `measured_actions[k]` ``）。题目和选项见 SPEC §8，描述你可以补充完善，但选项的键名不能改。
- 每个窗口调用一次 Jev，同一次请求里包含所有问题。
- 输出 `judgments.json`（SPEC §6.8）：score 归一化到 0–1，同时保留原始值；原始响应存为 `work/<clip_id>/raw/jev_<窗口>.json`。
- 某个窗口调用失败时，记为缺失（`null`），流程继续。

## E. scene 阶段（`stages/scene.py`，可选）

- 没传 `--scene` 且 config 中 `scene.auto: true`（默认）时：取片段中间一帧，调用一个支持图片输入的模型，生成一句英文场景描述（不超过 20 个词，只描述环境和机位，不评价人物，不说出人名），缓存为 `scene.json`。
- 在 `state` 之前运行；`state` 阶段读取它。调用失败时填 `"unknown"`，流程继续。
- 模型 ID 放 config。到 openrouter.ai/models 选一个便宜、支持图片输入的模型，报告里写明你选了哪个、价格多少。

## F. narrate 阶段（`stages/narrate.py`）

- 写解说的模型放在 config 的 `narrate.model`。到 openrouter.ai/models 选一个**便宜、快、中文好、支持 JSON 输出**的模型，报告里写明选择和价格。
- 提示词模板放在 `config/narrate_prompt.md`，输入是当前窗口的 state、judgments，以及上一个窗口的解说（保持连贯）。要求模型输出 JSON：`{"line": ..., "quote": ...}`。
- `line`：语言跟随 `--lang`；中文不超过 32 个字，英文不超过 16 个词。描述看得见、听得到的东西，加上 Jev 的判定。格式参考：「左手连续抬压、张开手掌强调，论述教育优势时表达欲持续走高」。
- **语气红线**（写进提示词，代码里也要检查）：
  - 不嘲讽，不下心理结论或道德评价（如「撒谎」「心虚」「装」）
  - 不编造 state 和 judgments 里没有的信息
  - 不猜测身份、动机或私人信息
- `quote` 必须是 `subtitle.current` 的原文子串：代码校验，不通过就取第一个分句。
- 输出 `narration.json`（SPEC §6.9），原始响应存进 `raw/`。
