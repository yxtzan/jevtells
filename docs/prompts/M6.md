## 2. 跨镜头认人

### 2a. 让跟踪知道镜头在哪里切换

M5 的硬切检测（HSV 分块直方图）现在在 `shots` 阶段，排在 `track` 之后。把检测逻辑抽成一个函数，让 `track` 也能调用（或者把硬切检测提前），`shots.json` 的格式不变。

### 2b. 记住主角长什么样

在每个 `--target` 锚点之后的 1 秒内，取主角的外观作为参考：

- 躯干区域（两肩到两髋围成的多边形）的 HSV 颜色直方图
- 上衣区域可以单独再取一份
- 多个锚点的参考都保留，不要在跟踪过程中不断更新（防止慢慢漂到别人身上）

### 2c. 跨过硬切时，按外观重新认人，不再按位置接着跟

- 新镜头开头的 10 帧里，算出每个检测到的人和参考外观的相似度（取中位数）。
- **只有同时满足**以下两条才认定是主角，否则整个镜头记为「主角不在画面」，直到下一个硬切或锚点：
  - 最高相似度 ≥ 阈值
  - 最高的比第二高的多出一个余量
- 锚点永远优先于自动认人。
- 镜头内跟丢后（例如被挡住），也可以用同样的规则按外观找回。这原本是计划在 v1.1 做的功能（SPEC §5.1 第 4 条）。
- 阈值和余量都放进 config。
- 每个镜头的判定写进 `track_meta.json`：选中了谁、相似度、第二高的相似度、判定结果（锚点 / 认出 / 不在画面）。

### 2d. 测试

至少覆盖：

- 硬切到另一个人 → 不在画面
- 硬切回同一个人 → 认出
- 两人同框 → 选中外观相符的那个
- 两人外观相近、余量不够 → 不在画面
- 锚点覆盖自动结果

**回归**：`jensen_cut` 在 M5 需要额外加锚点 `1@5`、`1@10` 才能跟上。现在只用 `--target 1@0` 应该就能自动认回来。

## 3. 主角不在画面的窗口不做判定

一个窗口里主角在画面中的时间少于 50% 时（比如切到主持人特写），看不到主角的手势，声音也可能是别人的。处理方式：

- 和「他人发言」一样处理：不调用 Jev 和解说模型，judgments 和 narration 记 null，并写明原因 `target_offscreen`。
- 解说位置显示灰字「（主角不在画面，本句不做判定）」。文字走 i18n，英文也要有。
- 他人发言和主角不在画面同时成立时，显示他人发言。

## 4. 核对主持人说话的区间

- 看 `transcript.json` 的词级时间戳，结合字幕内容和镜头，判断主持人从什么时候说到什么时候。
- 报告里给出最终的 `--others-speaking` 区间和依据（例如：哪几个词、哪个时间戳）。
- 这只是这段素材的命令行参数，**不要写进代码**。
