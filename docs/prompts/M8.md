## A. 选人

**现状**：先运行 `jevtells people VIDEO --at 秒`，得到一张标了号的截图；再用 `--target N@秒` 指定人。M6 起，切镜后会按衣服颜色重新认出这个人。功能有，但要自己看图记编号，不够直观。

**A1. `jevtells pick VIDEO [--at 秒]`：点一下选人。**
- 弹出标好号的画面窗口（OpenCV 窗口即可）。用户点击某个人，或者按数字键，就选中他。可以拖动时间滑条换一帧，再选一次，作为切镜后的锚点。
- 选择结果写进 `work/<clip_id>/target.json`（锚点列表）。之后 `run` 没传 `--target` 时，自动读取这个文件，并在终端打印「使用 pick 选定的目标：…」。
- 没有图形界面的环境（比如 SSH）里，这个命令报错，并提示改用 `people` 加 `--target`。
- 测试：选择结果的读写，以及 `--target` 优先级高于 `target.json`。

**A2. `--target-desc "白T恤、戴眼镜的男士"`：用一句话选人（实验功能，默认不用）。**
- 在锚点帧上，先用 Jev 1.14 的 noul 题问「画面里有没有符合描述的人」；答案是「有」时，再用 Box 题让它框出这个人。框和哪个检测到的人重叠最多（IoU 最高），就选谁。重叠不够、或者答案是「没有」时，直接报错，绝不猜。
- 评估：在 Tim 和黄仁勋两段素材里，至少挑 3 帧多人画面，每帧写 2 条描述（一条针对主角，一条针对旁人）。报告每条描述选中的是谁、对不对。

**A3. 移植 M7 的人脸认人到单人模式。**
- 锚点处，同时记录主角的人脸特征（YuNet + SFace，模型和下载、`doctor` 检查都沿用 M7 的实现）和衣服颜色。
- 切镜后认人的顺序是：人脸优先，衣服颜色其次；余量不够就判为不在画面。
- 回归：Tim 和黄仁勋两段在单人模式下逐帧的跟踪结果，和 v0.6.0 一致，或者差异可以解释。
- 用 `make_layout_variants.py` 的思路生成一段「同一个人换颜色」的测试素材（对上衣区域做色相偏移），证明靠人脸也能认回来。

**A4. 移植 M7 的 `--start auto`（只要单人模式）。** M7 里单人模式的结果是 4.033 秒，已经达标，移植后结果要一致。

## B. Jev 1.14 截图实验

**背景**：目前 Jev 只看文字，包括动作描述、声音描述和字幕，**看不到表情和神态**。Jev 1.14 可以收图片：PNG 或 JPEG，每边 256–1568px；图片按输入 token 计费；官方说明这是早期功能，格式和效果都可能变。文档：OpenRouter 的「Multimodal Decisions」指南。

**B1. 先打通一次调用。**
- 模型 `typesafe/jev-1.14`。用 `assets` 引用的方式传图，引用名用 UUID。
- 发一张图、一道题，确认请求格式、费用和耗时。原始响应存档。
- 如果需要特殊请求头，以实测为准，写进报告。

**B2. 开关 `--jev-images`，默认关闭。**
- 每个判定窗口取 3 帧：开始、中间、动作最明显的一帧。裁出主角的上半身（含脸和手），缩放到合规尺寸，存成 JPEG。
- 截图放进 state 的新字段 `frames`。这是 SPEC §6.7「正好 5 个字段」规则的例外，只在开关打开时出现，写进「偏离与决定」。
- 题目不变。可以在 instructions 里加一句「同时参考 frames 中的表情和姿态」。
- 截图存进 `work/<clip_id>/frames/`，方便人工核对。

**B3. 对比实验。** Tim（`tim_interview`，全片，单人模式，v0.6.0 的参数）和黄仁勋两段，每个窗口跑三组：
1. jev-1.13，只发文字（现状）
2. jev-1.14，只发文字
3. jev-1.14，文字加截图

每个窗口对比：三个分数、意图和情绪的结果及置信度、「不明显」的窗口数、耗时、费用。

另外生成 `work/M8/jev_images_review.md`：每个窗口一行，放 3 张缩略图、字幕和三组结果，方便人工判断哪一组更贴画面。**不要自己宣布哪组更准**，只给数据和你看图后的观察。

**B4. 画面里在说话的是不是主角（单人模式）。**
- 目标是减少手动填 `--others-speaking`。每个窗口给 Jev 主角的脸部截图（多帧），加上字幕，用 noul 题问「这句话是不是画面里这个人说的」。
- 用 `docs/samples.md` 里 Tim 和黄仁勋人工核对过的他人发言区间作参考答案，计算准确率，并和 M7 的嘴部动作方法对比。
- **只评估，不接进正式流程。**

**B5. 渲染一版看效果。** 用第 3 组（截图版）的判定，重写 Tim 的解说并渲染竖屏，输出 `work/_publish/tim_jevimg_v.mp4`。挑 3 个窗口，和现版本对比截帧。
