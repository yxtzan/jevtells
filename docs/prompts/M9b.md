# 任务：JevTells · M9b 界面重新设计（浅色工作台）

用户看了 M9 的界面，觉得不好看，要求重做。架构师出了三个方向，用户选了 **B「浅色工作台」**。

**设计稿**：本地 `design/ui/ui_B.html` 和 `ui_B.png`。`design/` 不提交，里面有版权画面。精确的颜色、圆角、间距以 HTML 里的 CSS 为准；`design/ui/ui_C_onboarding_reference.png` 只作为空状态和首次引导的语气参考。

## 这次改什么、不改什么

**改**：前端的结构和视觉，从「五个分开的深色页面」改成**一屏的浅色工作台**。视频、设置、时间轴同时可见，顶部的步骤条只用来提示「下一步做什么」，不再是翻页。

**不改**：
- 后端接口、参数映射、命令行行为、安全规则（只监听 127.0.0.1、key 只显示「已设置 / 未设置」、路径安全）。
- 不改成片的样式。
- M9 的全部功能都要保留。
- 同样的参数生成同样的结果，等价性测试必须照旧通过。

## 规则

- 不要停下来提问，没写清楚的地方按设计稿走，写进报告的「偏离与决定」。每完成一项就跑测试、提交、推送。
- 仍然只用 Python 加纯 HTML、CSS、JS，不加载外部 CDN。
- **文案只写功能，不写口号。** 删掉「把话，归给对的人」「这次，读谁？」这类标题，改成「框出要模糊的水印」「点一下画面里的人」这样直接说要做什么的话。中文为默认，英文同步。
- 不得修改 README、CHANGELOG、LICENSE、`docs/`、版本号。
- 分支 `m9b-ui-redesign`，从 main 拉出；commit message 以 `M9b:` 开头。不要合并，不要动 main。开始时执行 `git push origin main --follow-tags`。

## A. 视觉规范（来自设计稿）

**颜色**：

| 用途 | 色值 |
|---|---|
| 页面背景 | `#F4F3EF` |
| 卡片 | `#FFFFFF`，描边 `#E4E2DC`，圆角 18 |
| 正文 | `#141414` |
| 次要文字 | `#77746C` |
| 主按钮 | 黑底白字 |
| 荧光绿 `#C8FF2E` | **只用于点缀**：选中人物的标签、开关的圆钮、时间轴上主角说话的字幕块 |
| 「别人说」字幕块 | `#2B2B2B` |
| 水印框 | 橙色虚线 `#FF7A1A` |
| 播放头 | `#FF4D2E` |

**字体**：Noto Sans CJK SC，字重只用 400、600、800。输入框、开关、按钮的圆角是 10–12。

**尺寸**：基准 1440×900，最小 1180 宽。1280×800 下所有内容不重叠、不需要横向滚动。

## B. 布局

1. **顶栏**（高 64）：
   - 左：logo
   - 中：胶囊形步骤条「1 素材 · 2 主角 · 3 画面 · 4 说话人 · 5 生成」。已完成的步骤是黑字，当前步骤是白底加粗，未到的步骤是灰色。点击某一步，就把焦点切到对应的工具，不翻页。
   - 右：「历史」「设置」两个图标按钮，以及主按钮「生成成片 →」。必填项没完成时，主按钮置灰，鼠标悬停时提示缺什么。
2. **左侧画面卡片**：
   - 标题和一行提示，随当前步骤变化。比如「点一下画面里的人」「框出要模糊的水印」。
   - 视频画布上叠加：每个人的框和编号（点击选中；选中的人用黑框加荧光绿标签）、水印框（拖拽新建、拖动角调整大小、点 ✕ 删除）、检测到的字幕带（浅色描边）。
   - 画布下方有播放控件，和时间轴联动。
3. **右侧设置卡片**（宽 320）：
   - 主角名字、成片标题
   - 「设置」三项开关：原片已有字幕（已检测到）、切镜后按人脸认人、自动从主角开口处开始
   - 模糊区域，用标签列出
   - 分析范围
   - 预计耗时和费用
   - 最下方是可以折叠的「高级」：一句话描述选人、字幕来源、解说语言、画幅
4. **底部时间轴卡片**（通栏）：
   - 缩略图条，带切镜竖线；主角不在画面的时段用斜线纹标出
   - 字幕块轨道：Tim 是荧光绿，别人是深灰
   - 红色播放头
   - 右上角放图例
   - 交互和 M9 一样：点字幕块切换说话人，拖动可以刷出一段区间

## C. 状态

- **空状态**（还没选视频）：画面卡片里放一个大的拖放区「拖入视频，或从素材库选择」，下方列出 `samples/` 里已有的素材（缩略图、文件名、时长）。设置卡片和时间轴置灰。语气参考 `ui_C_onboarding_reference.png`。
- **选了视频之后**：自动在后台开始预处理（人物检测和字幕），进度用时间轴卡片顶部的细进度条和一行文字表示，比如「正在读取字幕 42%」。用户可以同时去选人、框水印，不必干等。
- **生成中**：画面卡片换成进度视图：阶段清单、当前阶段、耗时、费用，可以展开日志，有取消按钮。顶栏的主按钮变成「生成中…」。
- **完成**：画面卡片显示横屏、竖屏两个播放器并排，以及「下载横屏」「下载竖屏」「在 Finder 中显示」三个按钮。提示一句「只改标题、模糊、字幕样式时重新生成不花钱」。
- **历史、设置**：做成浅色的右侧抽屉或弹窗，不跳转到单独的深色页面。
