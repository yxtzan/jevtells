## 2. 标签和引线（替换 M5-fix 第 2 项的规则）

**原则**：几何约束只用于**按镜头选位置**。一旦某个动作的标签该显示，标签、引线、手部圆点三者必须同时完整画出，**任何一帧都不能因为几何原因隐藏标签或引线**。

**标签矩形的硬禁区**（不能压）：
- 脸框：由鼻、眼、耳、嘴的 pose 点算出外接框，四周扩 **0.15 倍**肩宽（上一轮是 0.35）
- 字幕条带 / 字幕条、模糊区域、判定卡片、界面元素、其他标签、安全边距

**软禁区**（可以压，但按重叠面积扣分）：躯干核心、手的活动范围。

**引线规则**（选位置时检查，不在逐帧绘制时隐藏）：
- **不穿脸**：引线不能穿过脸框（不扩边的那个框）。离手部端点 60px（设计尺寸）以内的部分不算：手抬到脸边时，引线停在手上是允许的。
- **不横穿身体**：引线不能越过身体中线（经过两肩中点的竖线），同样不算端点 60px 以内的部分。
- 一个位置合格的条件：该标签在这个镜头里显示的所有帧中，至少 95% 的帧满足以上两条。每帧都用真实的手部位置检查。

**选位置的顺序**：
1. 手所在的一侧（按镜头内手的中位位置在中线的哪一边判断，不按左右手名称），包括手的上方，满足全部规则的位置里分数最好的。
2. 对侧的位置，前提是满足全部引线规则。
3. 都没有：在手所在的一侧，只遵守硬禁区、放宽软禁区和引线规则，选分数最好的位置。记 `relaxed: true`。
4. 连硬禁区都无法满足时，在手所在的一侧选和脸重叠最少的位置，记 `forced: true`。
- **M4 的固定位置不再作为兜底使用。**

**`check_layout.py` 逐帧统计**：
- 标签矩形碰撞
- 引线穿脸帧
- 引线越过中线帧
- 被隐藏的标签帧
- 被隐藏的引线帧
- `relaxed` / `forced` 的次数

**目标**：
- 5 段两种画幅：碰撞 0、隐藏标签 0、隐藏引线 0。
- 穿脸帧不超过显示标签帧数的 2%；越过中线的帧如实报告。
- 每段素材实际显示过的标签数不少于 M5（黄仁勋原片 19、left 18、right 17、small 0、cut 5）。
  - 少了就说明原因。
  - small 是远景，按规则不显示，仍为 0。
